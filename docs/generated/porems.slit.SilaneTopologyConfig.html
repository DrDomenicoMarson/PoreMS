    SilaneTopologyConfig¶

    class porems.slit.SilaneTopologyConfig(itp_path: str, moleculetype_name: str = '', geminal_cross_terms: SilaneGeminalCrossTerms | None = None, junction_parameters: SlitJunctionParameters = <factory>)¶

    Flat ligand-topology input used by the slit full-topology exporter.

    Parameters:
    itp_pathstr

    Path to one self-contained flat GROMACS .itp file describing the base post-condensation T3 silane fragment, including the replacement surface silicon atom.

    moleculetype_namestr, optional

    Optional explicit molecule-type name expected inside itp_path. When omitted, the parser accepts the file’s own name.

    geminal_cross_termsSilaneGeminalCrossTerms or None, optional

    Optional explicit bonded terms used only when the exporter internally augments the base T3 fragment into a geminal T2 site by adding one silica OH group. This same helper also carries the optional retained-scaffold O-Si(mount)-first_ligand_atom angle needed by ligands whose first atom bound to the mount silicon is not oxygen. When the requested target includes geminal T2 sites, these terms are required. When no geminal sites are exported and the first ligand atom is oxygen, this can remain None.

    junction_parametersSlitJunctionParameters, optional

    Legacy silica-ligand junction parameters translated onto the resolved silica topology model when no explicit AmorphousSlitConfig.silica_topology is supplied.

    Notes

    The supplied flat ITP must be self-contained, must use atom names that exactly match the configured SilaneAttachmentConfig.molecule, and must already satisfy the total-charge target derived from the active silica model.
