    SlitTimingSummary¶

    class porems.slit.SlitTimingSummary(base_slit_build_s: float = 0.0, q_state_preparation_s: float = 0.0, t2_attachment_s: float = 0.0, t3_attachment_s: float = 0.0, finalize_s: float = 0.0, store_export_s: float = 0.0)¶

    Lightweight wall-clock timings for major slit-preparation stages.

    Parameters:
    base_slit_build_sfloat, optional

    Seconds spent building and preparing the unfunctionalized slit.

    q_state_preparation_sfloat, optional

    Seconds spent editing the slit surface to the requested prepared Q-state composition before any optional grafting.

    t2_attachment_sfloat, optional

    Seconds spent attaching the requested T2 population.

    t3_attachment_sfloat, optional

    Seconds spent attaching the requested T3 population.

    finalize_sfloat, optional

    Seconds spent in porems.slit_system.SilicaSlit.finalize().

    store_export_sfloat, optional

    Seconds spent writing the requested coordinate/topology export files.
