    Dice¶

    class porems.dice.Dice(mol, size, is_pbc)¶

    Partition a molecule into cubes for local pair searches.

    Parameters:
    molMolecule

    Molecule to be divided into cubes.

    sizefloat

    Cube edge size.

    is_pbcbool

    True when periodic boundary conditions should be applied during neighbor lookups.
